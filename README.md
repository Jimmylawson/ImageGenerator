# React + Vite

-Description:
A React-based web application that allows users to search for images using the Unsplash API. Users can enter a search term, and the app fetches and displays relevant images in a grid layout. This project demonstrates the use of React hooks like useState and useEffect, as well as external API integration with Axios. Styling is done using Tailwind CSS for a modern and responsive UI.

Features:
	•	Search images using the Unsplash API.
	•	Display results in a visually appealing grid format.
	•	Clear and minimalistic user interface.

Technologies:
	•	React
	•	Tailwind CSS
	•	Axios
	•	Unsplash API

How to Run:
	1.	Clone the repository.
	2.	Install dependencies with npm install.
	3.	Add a .env file with your Unsplash API key as VITE_REACT_APP_API_KEY.
	4.	Start the development server with npm run dev.
